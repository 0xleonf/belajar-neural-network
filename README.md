# Neural Network From Scratch with Pytorch

> Dibuat untuk memahami cara kerja kerja neural network secara sederhana.

---

## Fitur Utama
* **Forward Pass**: Implementasi perhitungan maju (fungsi linear & fungsi aktivasi berupa ReLU).
* **Autograd & Backpropagation**: Perhitungan turunan otomatis menggunakan fitur bawaan PyTorch.
* **Gradient Descent**: Proses optimasi parameter bobot dan bias secara mandiri.

---

## Prasyarat & Instalasi

Pastikan Anda sudah menginstal **Python** dan pustaka pendukung di komputer Anda.

1. **Clone repository ini**:
   ```bash
   git clone [https://github.com/username/nama-repo.git](https://github.com/username/nama-repo.git)
   cd nama-repo
   ```
2. **Unduh uv**
   ```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```
3. **Unduh pytorch & run file**
   ```bash
   uv pip install torch && uv run python nn_simple.py
   ```
